Personal Drive Backup
Privacy policy

Personal use · Application information

A private backup tool for personal files.

Personal Drive Backup is operated by eliranpv11 for the owner's own Google account. It uses Restic and rclone to create encrypted backups and store them in a designated Google Drive backup folder.

What the application does

The application runs on the owner's computer. It reads selected local files, encrypts them with Restic, and uploads backup data to the owner's Google Drive. It can read that data to check backup integrity and restore files. A separate local backup is created directly from the original files.

Why Google Drive access is requested

Google OAuth authorizes rclone to use the Drive API for backup storage and recovery. The configured authorization requests the full Drive scope, which permits viewing and managing Drive files. The backup automation is configured to operate on its designated backup repository; this scope itself is not limited to that folder.

The website does not sign you in to Google, receive authorization tokens, or store backup files. Authorization happens through Google's own consent screen and the locally running tool.

For the owner's personal use

This is not a public backup service. There are no customer accounts, subscriptions, or public sign-ups. This site provides application information for the Google OAuth configuration.

Read the privacy policy for details about data access, storage, retention, and revoking access.

Contact

Contact the maintainer through the documentation repository. Do not post backup contents, passwords, authorization codes, or tokens in public issues.
